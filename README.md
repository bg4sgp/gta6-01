**Vice Heat — Port Azura** is an original top-down open-world crime game that plays offline in a desktop browser from the static files in `game/`. Roam the neon beach city of Port Azura on foot or behind the wheel: steal cars, weave through traffic and pedestrians, outrun a five-star police response, clear your stars at the Shine & Go auto spa, and work a five-job story for fixer Viv Marchetti — then keep earning with endless cab fares. It has a cash/health HUD with a live minimap, title, pause, busted and finale screens, fully synthesized WebAudio sound, and a localStorage save. No network requests; every name, street and song in Port Azura is its own.

Controls: WASD or arrow keys walk and drive, Shift sprints and handbrakes, E enters and leaves cars, F punches, the mouse aims and a click shoots, P pauses, M mutes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `game/` and `screenshots/` into `out/` and writes `out/dossier.json`. To play, serve the `game/` folder with any static file server and open `game/index.html` in a desktop browser.
