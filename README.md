Vice Heat — Port Azura: an original top-down open-world crime game for the browser. Walk and drive a neon beach city, steal cars, outrun a five-star police response, work a five-mission story for fixer Viv, then run endless fares. Traffic, pedestrians, a repair shop that clears your stars, cash/health/minimap HUD, title, pause, busted and finale screens — no network requests; all audio is synthesized with WebAudio.

Controls: WASD drives and walks, E enters and leaves cars, Shift runs and handbrakes, F punches, the mouse aims and clicks to shoot, P pauses. Progress saves to localStorage.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

That writes `dossier.json` and a playable copy of the game into the output directory. To play, open `game/index.html` in a desktop browser (or serve the folder with any static server).
