## About this game

Vice Heat — Port Azura: an original top-down open-world crime game for the browser. Walk and drive a neon beach city, steal cars, outrun a five-star police response, work a five-mission story for fixer Viv, then run endless fares. No network; all audio is synthesized.

## Run it

Hand-in program (Node 22, standard library only) — writes `dossier.json` and a playable copy of the game into the output directory:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

To play, open `game/index.html` in a desktop browser (or serve the folder with any static server). WASD drives and walks, E enters and leaves cars, Shift runs and handbrakes, F punches, the mouse aims and clicks to shoot, P pauses. Everything renders and sounds locally; the game makes zero network requests.
